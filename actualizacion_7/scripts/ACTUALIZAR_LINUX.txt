ALTO TRAGO - Actualizacion rapida en Linux

Escenario:
- Proyecto instalado en disco local: ~/Downloads/Software Venta
- Carpeta de actualizacion en pendrive: /media/$USER/Ventoy/Software Venta/actualizacion_7

1) Dar permisos al script en pendrive:
chmod +x "/media/$USER/Ventoy/Software Venta/actualizacion_7/scripts/actualizar_linux.sh"

2) Si vas a usar interfaz nueva (React + Tauri), instala dependencias una sola vez:
sudo apt install -y build-essential curl wget file libgtk-3-dev libwebkit2gtk-4.1-dev \
  libayatana-appindicator3-dev librsvg2-dev patchelf

if ! command -v cargo >/dev/null 2>&1; then
  curl https://sh.rustup.rs -sSf | sh -s -- -y
  source "$HOME/.cargo/env"
fi

if ! command -v node >/dev/null 2>&1; then
  sudo apt install -y nodejs npm
fi

3) Migrar y ejecutar en modo React/Tauri (recomendado):
bash "/media/$USER/Ventoy/Software Venta/actualizacion_7/scripts/actualizar_linux.sh" \
  --project-dir "$HOME/Downloads/Software Venta" \
  --update-root "/media/$USER/Ventoy/Software Venta/actualizacion_7" \
  --ui tauri --rebuild --shortcut --desktop-icon

4) Si quieres mantener temporalmente la interfaz Python:
bash "/media/$USER/Ventoy/Software Venta/actualizacion_7/scripts/actualizar_linux.sh" \
  --project-dir "$HOME/Downloads/Software Venta" \
  --update-root "/media/$USER/Ventoy/Software Venta/actualizacion_7" \
  --ui python --shortcut --desktop-icon

5) Si no aparece en el menu, instala tambien acceso directo global:
bash "/media/$USER/Ventoy/Software Venta/actualizacion_7/scripts/actualizar_linux.sh" \
  --project-dir "$HOME/Downloads/Software Venta" \
  --update-root "/media/$USER/Ventoy/Software Venta/actualizacion_7" \
  --ui tauri --shortcut-global --no-run

El script hace:
- Cierra la app.
- Hace backup de data y tickets en ~/alto-trago-backups
- Aplica todos los archivos de codigo de la carpeta actualizacion_7 (excepto scripts y txt)
- Detecta runtime de UI (python/tauri) segun --ui
- En modo Tauri usa la misma base de datos local (VENTA_DB_PATH)
- Opcional: recompila runtime activo (--rebuild)
- Opcional: crea/actualiza acceso directo en ~/.local/share/applications/alto-trago.desktop
- Refresca menu con update-desktop-database, xdg-desktop-menu forceupdate, limpia ~/.cache/menus y reinicia xfce4-panel
- Opcional: copia acceso directo a /usr/share/applications (requiere sudo)
- Opcional: crea icono directo en ~/Desktop o ~/Escritorio

Si aun no aparece en el menu:
1) Cerrar sesion e iniciar sesion nuevamente.
2) Probar lanzamiento directo:
   gtk-launch alto-trago
